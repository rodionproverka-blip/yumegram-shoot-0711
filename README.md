# Съёмочная карта YumeGram — 07.11

Статический сайт для команды. Внутри сценарии, покадровые ориентиры, подготовка света и камеры, чек-листы и печатный реквизит.

- `index.html`, `style.css`, `app.js` — интерфейс.
- `plan.js` — сценарии, проверки и список реквизита.
- `assets/frames/` — стоп-кадры Tifa и тир-листа и мультяшные раскадровки для остальных роликов.
- `assets/print/` — готовые файлы Word для печати.

Страницы работают на GitHub Pages без сборки. Отметки хранятся в общей базе и обновляются на открытой странице примерно раз в пять секунд. При первом открытии новой версии браузер добавляет свои прежние галочки к общим. Ранее снятые в общей базе галочки не восстанавливаются из старой копии. При проблемах со связью новые отметки остаются в браузере и отправляются после восстановления соединения.
